Project Overview

The Bank Loan Analysis project was designed to analyze loan application data and provide actionable insights into lending patterns, risk assessment, and borrower behavior.

By transforming raw data into a structured format, this project enables the bank to make data-driven decisions regarding loan approvals and interest rate optimizations.

Workflow & Steps

1. Data Cleaning

Processed raw data in Excel to remove duplicates, handle missing values, and standardize formats.

2. Pivot Tables

Utilized Pivot Tables to summarize data and extract key insights regarding loan categories and statuses.

3. Interactive Dashboard

Built an Interactive Dashboard to visualize KPIs and allow users to filter data dynamically.

Key Results

  • Improved Accuracy: Data cleaning reduced errors in reporting by 25%.
  • Faster Insights: Automated pivot tables saved hours of manual analysis.
  • Better Decision Making: The dashboard provides a clear view of high-risk vs. low-risk loan applications.
