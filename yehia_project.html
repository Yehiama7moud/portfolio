Project Overview

This project focuses on building a robust data pipeline and interactive dashboard using Power BI. The primary objective was to establish a seamless connection to a live Database through ODBC, ensuring that the data remains up-to-date and reliable for decision-making.

A significant part of the workflow involved using Power Query to perform extensive data cleaning and transformation. This included handling null values, standardizing data formats, and merging multiple tables to create a unified data model optimized for performance and clarity.

The final outcome is a comprehensive Power BI report that provides actionable insights, allowing stakeholders to monitor key performance indicators (KPIs) and trends in real-time.

Recommendations

  1. Maintain the ODBC connection with proper security protocols to ensure data safety.
  2. Regularly audit the Power Query steps to optimize refresh times as the database grows.
  3. Implement incremental refresh in Power BI for large datasets to improve performance.
  4. Document the data dictionary and transformation logic for future maintenance.
  5. Gather user feedback periodically to refine dashboard visuals and usability.
