Project Overview

This project demonstrates a complete data lifecycle, starting from raw Excel data and transforming it into a high-performance MySQL Database. The primary goal was to move beyond flat files and leverage the power of relational databases for more complex analysis.

Once the data was migrated to MySQL, I performed deep-dive analysis using advanced SQL Queries. This included utilizing GROUP BY and ORDER BY for aggregation, complex JOINS to connect disparate tables, and Window Functions to calculate running totals and rankings.

The final phase involved connecting this MySQL database to Power BI. I used Power Query for final cleaning and established a robust Data Model. The result is an interactive dashboard featuring Custom Visuals that provide unique insights into the data trends and performance metrics.

Recommendations

  1. Optimize MySQL indexes to ensure fast query performance as the dataset grows.
  2. Use View objects in MySQL to pre-aggregate data before importing into Power BI.
  3. Regularly validate data integrity between the source Excel files and the MySQL database.
  4. Leverage DAX in Power BI for time-intelligence calculations based on the SQL-processed data.
  5. Document the SQL transformation logic to ensure maintainability of the data pipeline.
